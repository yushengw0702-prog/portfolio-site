# 飞书宋体 + 米白主题（Chrome 扩展）

让浏览器版飞书（feishu.cn / larksuite.com）使用**宋体**正文 + **米白背景**。

## 在新机器（如家里的 Mac mini）安装

1. 在这台机器的 Chrome 打开：本仓库页面 https://github.com/yushengw0702-prog/portfolio-site
   → 绿色 **Code** 按钮 → **Download ZIP**，解压。
   （或者只下载 `feishu-theme` 这个文件夹也行。）
2. Chrome 地址栏输入 `chrome://extensions`
3. 右上角打开 **开发者模式**
4. 点 **加载已解压的扩展程序**，选中解压出来的 `feishu-theme` 文件夹
5. 刷新飞书页面 —— 字体变宋体、背景变米白

> 只影响外观，不读取任何数据；纯本地 CSS。
> 在浏览器登录飞书用你自己的账号即可，扩展与账号无关。
